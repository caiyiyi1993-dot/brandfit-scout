# BrandFit Scout

一个免费、本地优先的海外社媒 Influencer 合作初筛工具，覆盖 YouTube、Instagram 和 TikTok。

它不是“粉丝越多越好”的排行榜，而是把品牌画像与创作者公开信号放进同一套透明规则中，输出：

- 品牌调性匹配度与内容风格
- 受众 / 地区线索（明确标注为线索，不冒充后台受众数据）
- 商业化密度与品牌安全风险项
- 互动质量、数据稳定性与异常提醒
- 0–100 总分、证据置信度和合作建议

## 30 秒运行

无需安装依赖。在项目目录启动任意静态文件服务：

```bash
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000`。由于页面使用浏览器原生 ES Modules，请通过上述本地服务打开，不要直接双击 `index.html`。

先点“载入示例”可体验完整报告。

## 数据获取方式

| 平台 | MVP 默认方式 | 能得到什么 | 主要限制与降级 |
|---|---|---|---|
| YouTube | 官方 Data API v3（可选 API Key） | 频道简介、地区、订阅数、最近公开视频及播放/点赞/评论 | 分享数不是公开视频字段；无 Key 或配额用尽时改为 CSV/JSON 或手工录入 |
| Instagram | CSV/JSON 或手工录入公开资料 | 用户可见的 Bio、粉丝量和近期内容指标 | 官方 API 不支持任意普通个人账号；专业账号数据也受权限与授权关系限制 |
| TikTok | CSV/JSON 或手工录入公开资料 | 用户可见的 Bio、粉丝量和近期内容指标 | Display API 要创作者授权；Research API 只面向符合条件的研究者；不可把商业产品建立在该入口上 |

YouTube API Key 只存在当前页面内，不会写入 localStorage 或发送给本项目之外的服务。项目本身没有后端，也没有遥测。

## 导入格式

每行手动输入：

```text
标题或文案 | 播放/浏览 | 点赞 | 评论 | 分享
```

CSV 表头支持英文或中文：

```csv
title,views,likes,comments,shares
My honest gear review,82000,6300,284,190
```

JSON 支持数组或 `{ "posts": [...] }`：

```json
[
  {"title":"My honest gear review","views":82000,"likes":6300,"comments":284,"shares":190}
]
```

## 评分方法

总分是六项透明加权结果：品牌调性 30%、内容风格 15%、受众/地区 15%、商业化适配 10%、品牌安全 15%、互动质量 15%。

- 文本主题匹配采用显式关键词覆盖，不调用付费 AI。
- 互动率按每条内容 `(点赞 + 评论 + 分享) / 播放或浏览` 计算，并用中位数降低爆款干扰。
- 稳定性用近期内容播放量变异系数估算；波动过大时降低互动质量分。
- 商业化密度通过 `#ad`、`paid partnership`、`affiliate`、折扣码等披露词初筛。
- 风险识别只触发“人工复核”，不把关键词命中直接判为违规。
- 置信度独立于总分：数据越少，即使匹配分高也不会直接建议优先洽谈。

所有规则都在 [`src/scoring.js`](src/scoring.js) 中，可按品牌调整词表、阈值与权重。

## 免费 / 开源方案调研结论

完整调研与平台限制见 [`docs/research.md`](docs/research.md)。可借鉴的开源组件包括 Instaloader、TikTok-Api、yt-dlp，以及自托管的 InfluenceX；但非官方抓取器容易因页面变化、登录限制或平台条款而失效，所以本 MVP 没有把它们设为默认数据源。

## 产品边界

这是合作前初筛与证据整理工具，不是：

- 对创作者或受众身份的事实认证
- 对假粉、品牌安全或合规的最终结论
- 对合作效果、销售转化或 ROI 的保证

决定合作前仍需人工抽看内容与评论，并要求创作者提供平台后台受众截图。请遵守平台条款、隐私和适用广告披露法规。
